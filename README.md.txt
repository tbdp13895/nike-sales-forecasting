# Nike Sales Forecasting

This project analyzes Nike sales data and builds a time-series forecasting model
(using Prophet) to predict future monthly sales.

## Contents

- `data/raw/` – Original dataset (Nike Dataset.csv)
- `notebooks/` – Exploratory analysis & forecasting notebook
- `reports/` – Charts and summaries
- `other/` – Power BI dashboards, slides, etc.

## Goal

- Understand sales trends over time.
- Build a forecasting model to predict future monthly sales.
- Derive business insights from model performance.
